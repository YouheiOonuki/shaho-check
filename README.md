# 社会保険 加入チェッカー

公開 URL: **https://yorozu-craft.com/shaho-check/**

パート・アルバイトの方が、自分が社会保険（厚生年金・健康保険）の加入対象かを、質問に答えるだけで確認できるツールです。
2026年10月1日の賃金要件（いわゆる「106万円の壁」）の撤廃と、2027年以降の企業規模要件の段階的な縮小に対応しています。
yorozu-craft のツールの1つです（共通ルールは [youheioonuki.github.io の README](https://github.com/YouheiOonuki/youheioonuki.github.io) を参照）。

## 機能

- 週の労働時間・勤務先の規模・雇用期間・学生かどうか・正社員との比較（4分の3基準）から、加入の対象かを判定
- 対象外の場合、会社の規模の条件が下がって**いつから対象になるか**を表示
- 月の給与を入れると、標準報酬月額の等級に当てはめて、加入した場合の保険料（本人負担）の目安を表示
- 判定の根拠（法律・公式ページ）と最終確認日を画面に表示。確認日から6か月たつと注意を表示
- 入力のたびに自動で判定（ボタン不要）。入力内容は保存も送信もしない
- 解説ページ（何が変わったか、スケジュール表、加入するとどうなるか、よくある質問）

## 判定の根拠（一次情報で確認済み。確認日は `judge.js` の `CHECKED`）

根拠となる法律: 社会経済の変化を踏まえた年金制度の機能強化のための国民年金法等の一部を改正する等の法律（令和7年年金制度改正法。2025年6月13日成立）

| 条件 | 内容 | 出典 |
|------|------|------|
| 賃金要件 | 月額8.8万円以上 → **2026年10月に撤廃** | 日本年金機構「適用拡大のご案内」 |
| 企業規模要件（厚生年金の被保険者数） | 51人以上 → 2027年10月 36人以上 → 2029年10月 21人以上 → 2032年10月 11人以上 → 2035年10月 撤廃 | 厚生労働省「特設サイト」の判定と同じ区分 |
| 国・地方公共団体 | 人数に関係なく対象 | 日本年金機構「適用の拡大」 |
| 労働時間 | 契約上の週の所定労働時間が20時間以上（月単位なら ×12÷52） | 同上 |
| 雇用期間 | 2か月以内の期間を定めて使用される人は対象外 | 同上 |
| 学生 | 昼間の学生は対象外。夜間・定時制・通信制・休学中・卒業後も同じ事業所に勤める予定の人・社会人大学院生などは対象 | 年金Q&A（厚生年金保険法施行規則第9条の6） |
| 4分の3基準 | 週の所定労働時間**または**月の所定労働日数が正社員の4分の3未満なら短時間労働者。両方4分の3以上なら規模・学生に関係なく加入 | 日本年金機構「適用の拡大」・年金Q&A |
| 保険料の目安 | 月の給与を標準報酬月額の等級（健康保険 1〜50 等級、厚生年金 1〜32 等級 88,000〜650,000円）に当てはめ、等級の額 × 料率 ÷ 2。料率は厚生年金 18.3%、健康保険 9.9%（協会けんぽの令和8年度の平均）、子ども・子育て支援金 0.23%。1円未満は50銭以下切り捨て・50銭超切り上げ（額表の注①）。介護保険は金額を出さず注記のみ。値は `judge.js` の `RATES`・`GRADES_KENPO`（確認日 `PREMIUM_CHECKED`） | 協会けんぽ 保険料額表（令和8年3月分から）・令和8年度保険料率、日本年金機構 保険料額表（令和8年度版） |
| 保険料調整制度 | 勤務先が使う場合、新たに加入した人の保険料負担を通算3年間軽減（3年目は半分） | 厚生労働省「特設サイト」支援制度 |

個人経営の事業所は、ツールでは断定せず「勤務先に確認」と案内しています。

## 保守（このツールを公開し続ける責任として）

画面に「判定の根拠と確認日」を出しています。確認日（`CHECKED`）から6か月たつと、画面に「情報が古い可能性があります」と自動で表示されます。次のタイミングで一次情報を確認し直し、`CHECKED` と必要な値を更新してください。

| 時期 | 確認すること | 直す場所 |
|------|------------|---------|
| 毎年3〜4月ごろ | 保険料率（協会けんぽの平均・子ども・子育て支援金・厚生年金）と保険料額表の改定 | `judge.js` の `RATES`・`GRADES_KENPO`・`PREMIUM_CHECKED`・`PREMIUM_SOURCES` |
| 2027年8月ごろ（9月分から厚生年金の上限が68万円） | 日本年金機構の新しい額表（上に足される等級の報酬月額の区切り） | `judge.js` の `PENSION_MAX` と等級の区切り |
| 2027年8月ごろ（36人以上への拡大の前） | 段階のスケジュールに変更がないか | `judge.js` の `SIZE_STEPS`、`guide.html` のスケジュール表 |
| 6か月ごと（画面に注意が出る前） | 公式ページの更新日と内容 | `judge.js` の `CHECKED`・`SOURCES`、`guide.html` の最終確認日 |

**値や判定を直したら、`guide.html` の「更新履歴」に日付と内容を 1 行足す**（本名で公開しているツールなので、何をいつ直したかを隠さない。誤りを直した場合もそう書く）。
