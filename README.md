# 社会保険 加入チェッカー

公開 URL: **https://yorozu-craft.com/shaho-check/**

パート・アルバイトの方が、自分が社会保険（厚生年金・健康保険）の加入対象かを、質問に答えるだけで確認できるツールです。
2026年10月1日の賃金要件（いわゆる「106万円の壁」）の撤廃と、2027年以降の企業規模要件の段階的な縮小に対応しています。
yorozu-craft のツールの1つです（共通ルールは [youheioonuki.github.io の README](https://github.com/YouheiOonuki/youheioonuki.github.io) を参照）。

## 機能

- 週の労働時間・勤務先の規模・雇用期間・学生かどうか・正社員との比較（4分の3基準）から、加入の対象かを判定
- 対象外の場合、会社の規模の条件が下がって**いつから対象になるか**を表示
- 月の給与を入れると、加入した場合の保険料（本人負担）の目安を表示
- 入力のたびに自動で判定（ボタン不要）。入力内容は保存も送信もしない
- 解説ページ（何が変わったか、スケジュール表、加入するとどうなるか、よくある質問）

## 判定の根拠（2026年9月時点）

| 条件 | 内容 |
|------|------|
| 賃金要件 | 月額8.8万円以上 → **2026年10月1日に撤廃** |
| 企業規模要件（厚生年金の被保険者数） | 51人以上 → 2027年10月 36人以上 → 2029年10月 21人以上 → 2032年10月 11人以上 → 2035年10月 撤廃 |
| 労働時間 | 契約上の週の所定労働時間が20時間以上 |
| 雇用期間 | 2か月を超える見込み |
| 学生 | 昼間の学生は対象外（夜間・通信制・定時制・休学中は対象） |
| 4分の3基準 | 正社員の所定労働時間・日数の4分の3以上なら、規模・学生に関係なく加入 |

個人事業所の扱いと、新たに加入する人の保険料負担を軽くする支援策の細かい条件は、ツールでは断定せず「勤務先に確認」と案内しています。

**制度が変わったら `judge.js` の定数（`WAGE_ABOLISHED`・`SIZE_STEPS`・`RATES`）と、`guide.html` の説明・スケジュール表を更新してください。**

## ファイル

| ファイル | 役割 |
|---------|------|
| `index.html` | チェッカー本体 |
| `judge.js` | 判定ロジックと保険料の目安の計算（画面から切り離した純粋関数） |
| `app.js` | 画面の制御（入力のたびに判定して表示） |
| `guide.html` | 解説・スケジュール・よくある質問（FAQ の構造化データつき） |
| `about.html` / `privacy-policy.html` | yorozu-craft 共通の運営者情報・プライバシーポリシー（`../about.html` など）へ移動する案内ページ |
| `style.css` | yorozu-craft 共通の和紙風の配色 |
| `favicon.svg` / `og-image.png` | ファビコン / SNS 共有用画像（1200x630） |
| `sitemap.xml` | サイトマップ（robots.txt はドメイン直下で管理） |
| `tests/judge.test.js` | 判定ロジックのテスト（`node tests/judge.test.js`） |
